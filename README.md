# J.P. Morgan Quantitative Research Virtual Experience

Completed the J.P. Morgan Quantitative Research Virtual Experience Program on Forage.

## Tasks Completed

### Task 1: Natural Gas Price Forecasting

* Analyzed historical natural gas prices
* Estimated prices for future dates

### Task 2: Commodity Storage Contract Pricing

* Built a storage contract valuation model
* Included storage costs and operational constraints

### Task 3: Credit Risk Analysis

* Developed a Probability of Default (PD) model
* Calculated Expected Loss (EL)

### Task 4: FICO Score Bucketing

* Bucketed FICO scores into risk categories
* Estimated default probabilities by bucket
